## 一、登录与账号

1. 打开系统地址（本地 `http://localhost:8687`，或线上演示站）
2. 输入账号与密码，点击「登 录」
   - 初始账号：`teacher`（教学总监）/ `wangli`（教研组长），初始密码均为 `zx123456`
3. 登录后默认进入**组卷台**；顶栏右侧显示当前身份与模式
4. 修改密码：顶栏「修改密码」→ 输入原密码与新密码（至少 6 位）→ 保存
5. 退出：顶栏「退出」（只清除登录态，不影响已保存的数据）

## 二、教师篇：题库管理

### 2.1 新增一道试题

1. 顶栏「题库」页签 → 点「＋ 新增试题」
2. 逐项填写：
   - **科目**（必填）：从分组下拉选择；若科目不存在，选「＋ 新增科目…」直接输入新名称
   - **题型**（必填）：单选 / 多选 / 判断 / 填空 / 简答 / 写作 / 口语
   - **难度**：1 基础 ~ 5 挑战（智能组卷的三层分布按 1–2 / 3 / 4–5 归带）
   - **知识点**：直接输入（顿号分隔），或点「从大纲选择」勾选
   - **材料/文章**：阅读文章、听力原文等（可选）
   - **题干**（必填）：数学公式用 `$...$` 包裹，如 `$x^2+1$`
   - **选项**：仅选择题显示；每行一个，无需写 A. B. 前缀
   - **答案**：单选填字母（A）；多选填字母逗号分隔（A,C）；判断选对/错；其余填参考答案或评分要点
   - **解析**：打印教师卷时会随答案展示（建议填写）
   - **建议分值 / 建议用时**：组卷时的默认值
   - **听力音频**：听力题上传 mp3/wav/m4a（在线答题时学生可播放）
   - **题目配图**：几何图/图表等 png/jpg（≤5MB）
   - **可见范围**：共享题（全体教师可用）或私有题（仅自己与教学总监可见）
3. 点「保存试题」。**输入题干时会自动查重**——如提示相似题，请先确认是否重复录入

### 2.2 找题与筛选

题库页顶部支持组合筛选：**关键词搜索**（题干/材料/知识点/来源）+ 科目 + 题型 + 难度 + 状态。筛选结果实时更新。

### 2.3 批量操作

1. 勾选题目前的复选框（支持表头全选），底部浮条显示已选数量
2. 一键执行：启用 / 停用 / 收藏 / 取消收藏 / 删除
3. 删除 = 进入**回收站**（可恢复），并自动从所有包含它的试卷中移除；彻底删除请在回收站内操作

### 2.4 收藏与用卷次数

- 每题行首 ★ 可收藏/取消收藏；「用卷」列显示该题被组卷引用的次数（≥3 次标红提醒）
- 私有题带 🔒 标记，仅创建者与教学总监可见可改

## 三、教师篇：真题库与录题

真题库用于管理**历年真题**（Paper 元数据 + 整卷 QP/MS 文件），与普通题库分开。

### 3.1 录入一套真题卷

1. 顶栏「真题库」页签 → 点「＋ 新建真题卷」
2. 填写：Paper（P1 / P2）、年份、考季（January / June…）、卷号（如 WMA11/01）、状态
3. 上传两份 PDF：**Question Paper**（题目卷）与 **Mark Scheme**（评分卷）
4. 保存后列表中可直接点 QP / MS 在线查看

### 3.2 状态说明

- **已发布**：学生刷题端可见
- **草稿**：仅管理端可见
- **已下架**：全部隐藏（题目本身保留）

## 四、教师篇：组卷工作台

组卷台是系统的核心，采用**双栏工作区**：左侧试题池挑题，右侧试卷实时成型。

### 4.1 手动组卷（最常用）

1. 填写顶部**试卷名称**（必填）、卷面科目行、时长；需要 A/B 卷时选择卷型标记
2. 左侧试题池：用搜索/科目/题型/难度筛选，点题目右侧的 **＋** 加入右侧试卷
   - 题目按题型自动归入大题；大题可**改名**（改名后再加题会固定进入该大题）、上下移动、删除
3. 右侧试卷中每题可：**改分值**、**换题**（弹窗按难度就近列出同池候选，点选即换且保留分值）、区内 ↑↓ 调序、移除
4. 题目行可直接**拖拽**换位；拖入其他大题区域会自动归入该大题
5. 顶部实时显示：题数 · 总分 · 时长（留空自动按题汇总）· **难度构成条**（基础/强化/冲刺）
6. 点「保存试卷」（存草稿/定稿）或「保存并打印」（直接打开学生卷打印页）

### 4.2 按配置自动生成

点右侧「按配置生成」弹窗，两种模式：

- **快速模式**：勾选科目 + 填总题数 → 一键按题库题型分布自动配卷，分值凑满 100 分
- **精确模式**：逐题型设数量×分值，再设难度三层分布（基础 1–2 / 强化 3 / 冲刺 4–5 按比例抽题），可限定知识点

生成结果直接填入工作区，之后照常手工微调。**抽不满会如实提示**（如「判断题 仅 2/5 题」）。

### 4.3 组卷蓝图（模板复用）

- 「存为蓝图」：把当前试卷的题型配置、难度分布、范围科目存成模板
- 「载入」：选蓝图一键生成一套新卷，适合周测等固定结构的重复出卷

### 4.4 平行卷（A/B 卷）

生成预览后点「生成平行卷（避开本题）」：系统避开当前所有选题再抽一套，并自动标记 B 卷。题库储备不足时会提示缺口。

### 4.5 从题库直接加题

题库页每行有「加卷」按钮，点击直接把该题送入组卷台当前试卷；也可以在题库先「入篮」攒一批再去组卷台。

## 五、教师篇：考试与成绩

### 5.1 创建考试

1. 顶栏「考试」页签 →「＋ 创建考试」
2. 填考试名称、关联试卷（从试卷库选）、考试日期、备注
3. 勾选**考生名单**（花名册勾选，或在文本框按「姓名，班级」每行一人批量粘贴——自动去重并加入花名册）
4. 勾选「**开启学生在线作答**」→ 系统生成 6 位答题码；点列表中的「复制学生链接」发给学生
5. 保存后进入录分视图

### 5.2 学生在线作答（免登录）

学生打开登录页「在线答题」入口（或老师发的链接），输入**答题码 + 姓名**（须与考生名单一致）：

- 客观题点选作答；听力题可播放音频；主观题在文本框输入
- 交卷后**客观题自动判分**（单选/判断全对满分；多选全对满分、漏选半分、错选 0 分），主观题进入待批阅
- 交卷即显示客观题得分；重复交卷覆盖全部成绩；考试「完结」后不能再进入

### 5.3 录分与批阅

「录分」视图左侧为考生列表，右侧按题录分：

- **客观题**：已在线判分的自动带出；纸质卷可用每题的 ✓/✗ 按标准答案快速判分，或「客观题全对 / 全错」一键处理
- **主观题**：学生在线作答原文直接显示在对应题目下方，对照打分
- 每题分值超出满分会被自动截断；点「保存本科目成绩」整份保存
- 纸质卷可点「上传答题卡照片」挂在考生名下，对照录入

### 5.4 统计报告

点「报告」查看自动生成的分析：平均/最高/最低/中位数/及格率、分数段分布、成绩排名（🥇🥈🥉）、每题得分率（<50% 红色预警）、**薄弱知识点榜**（按知识点聚合得分率）、讲评建议。点「导出成绩单」下载 Excel（含名次、每题得分、统计摘要）。

### 5.5 考试状态

- **完结**：学生不能再进入在线作答，录分仍可修改
- **重开**：恢复在线作答

## 六、打印与导出

试卷库每套卷提供「学生卷」「教师卷」两个打印入口（组卷台保存并打印直接打开学生卷）：

- **学生卷**：完整题目与作答区，不含答案
- **教师卷**：同卷 + 文末另起一页附全部答案与解析
- **答题卡**：客观题涂卡气泡、判断题对/错、填空作答行、简答/写作作答框
- **密封线**：工具栏开关，开启后左侧出现红色装订线（设置会记忆）
- **导出 Word**：生成 .doc 文件，可用 Word / WPS 继续编辑
- **打印 / 导出 PDF**：调起浏览器打印，选择「另存为 PDF」；A4 版式自动分页，听力题会印出音频提示

## 七、学生篇：在线答题与刷题

### 7.1 在线答题

1. 打开登录页下方「在线答题」入口（或直接打开老师发的链接）
2. 输入老师提供的 **6 位答题码** 和 **姓名**（须与老师登记一致）
3. 逐题作答：选择题点选、判断题选对/错、主观题文字输入；听力题点播放器收听
4. 点「交卷」确认后立即显示客观题得分；页面可关闭

### 7.2 刷题与收藏

登录后进「刷题」页签：选 P1/P2 → 点知识点药丸 → 按年份/考季/难度筛选 → 点卡片查看详情（可展开 Mark Scheme）→ ♡ 收藏。「我的收藏」面板查看全部收藏。

## 八、数据管理与备份

「审计」页签底部：

- **导出备份**：一键下载全库 JSON（题目/试卷/考试/名单/蓝图/成绩），建议每周一次
- **从备份恢复**：选择备份文件覆盖当前数据（账号不受影响）；**恢复前请先导出一份当前数据**
- 注意：备份 JSON 不含上传的图片/音频/PDF 文件，迁移电脑时请一并拷贝 `backend/uploads/` 目录

## 九、常见问题 FAQ

| 问题 | 处理 |
|---|---|
| 登录提示「账号或密码不正确」 | 确认账号 teacher / wangli；忘记密码请联系教学总监重置（后台重置） |
| 学生说「姓名不在考生名单中」 | 检查在线答题输入的姓名与创建考试时是否完全一致（含多音字写法） |
| 学生说「答题码不正确」 | 答题码不区分大小写；确认考试状态为「进行中」且在线作答未关闭 |
| 搜不到某道题 | 检查题目状态是否为「停用」、是否为他人私有题、或已进入回收站 |
| 公式显示为原始代码 | 公式必须用 `$...$` 包裹；编辑题目时检查美元符号是否成对 |
| 音频/图片上传失败 | 检查格式（mp3/wav/m4a、png/jpg）与大小（音频 20MB / 图片 5MB）；演示模式不支持上传 |
| 打印时公式被截断 | 浏览器打印设置中勾选「背景图形」；题干过长可调小缩放比例 |
| 组卷提示「仅 x/y 题」 | 该筛选范围内题库储备不足，按提示去题库补题或放宽条件 |
| 改了页面没变化 | 浏览器缓存——按 Ctrl+F5 强制刷新 |
| 想清空演示数据 | 演示模式关闭标签页即重置；服务端模式删除 `backend/zujuan.db` 后重启 |
