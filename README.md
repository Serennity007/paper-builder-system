> **文档入口**：[使用者操作手册 docs/USER-GUIDE.md](docs/USER-GUIDE.md)（教师/学生分篇操作指引+FAQ）· [开发协作手册 docs/HANDBOOK.md](docs/HANDBOOK.md)（架构/API 全表/约定/测试/部署/避坑）· [产品需求 docs/PRD.md](docs/PRD.md)（16 章规划与迭代计划）

> 成都智慧象留学 · 教研组卷工作台　|　交付日期：2026-09-28（v3 在线答题增强同日）　|　独立于「学生进度追踪系统」的新系统

面向国际课程教学场景（IELTS / TOEFL / A-Level / AP）的教研系统，**以组卷为核心**：登录即达组卷台，一键组卷；题库、在线考试与成绩分析围绕组卷协作。
与学生进度追踪系统（04，端口 8686）同一套技术栈与视觉规范，本系统独立运行在 **8687 端口**，两套系统可同时开启。

## 快速启动

```bash
cd 06-组卷系统
python backend/app.py     # 服务端模式（推荐）：Flask + SQLite 持久化 → http://localhost:8687
python server.py          # 纯静态演示模式：sessionStorage，关标签页即重置（汇报现场兜底）
```

或双击 `一键启动-组卷系统.bat`。前端 `js/api.js` 自动探测 `POST /api/ping`，两种模式页面代码通用、
核心功能对齐（在线答题/报告/回收站/蓝图/知识树演示模式同样可用，上传/导入/审计除外）。

**依赖**：Python 3.11+，`pip install -r backend/requirements.txt`（flask、openpyxl）。演示模式无任何依赖。
**KaTeX 已内置离线包**（`vendor/katex/`），公式渲染不依赖外网。
**邮箱验证码登录**：默认为开发模式——验证码不经真实邮件发送，直接回显在登录页与后端控制台，本地零配置可联调；
接入正式邮箱时新建 `backend/email_config.json`（模板见 `docs/HANDBOOK.md` 认证一节），设 `enabled:true` 并填 SMTP 账号即可切换为真实发信。

## 在线答题规则

- 答题码由创建考试时勾选「开启学生在线作答」生成（6 位，去除易混字符），也可在列表随时开启/关闭
- 学生须使用与考生名单一致的姓名；交卷后客观题立即判分并写入成绩，重复交卷整份覆盖
- 主观题（填空/简答/写作/口语）存作答原文，教师在「录分」视图对照原文打分
- 考试完结（状态改「已完结」）后学生不能再进入

## 工程约定（改版必读）

1. 静态资源版本参数 `?v=20261001b`，**改 css/js 后必须升版本号**（两种启动方式都发 no-cache 头）
2. 视觉规范：2026-10-01 起升版为「纸阅 Atelier」设计系统（`css/style.css` 顶部 tokens）：墨蓝 #0E1B2C 系 × 香槟金 #C9A85C 系 × 暖纸面 #F4F1E9，DengXian/雅黑 + Segoe UI（数字 tabular-nums），金色只做点缀；动效层 `js/micro.js`（进场编排/数字滚动/分布条生长/按钮涟漪，尊重 prefers-reduced-motion，可整体降级）；水印 made by Jessie 保留
3. Excel 导入列规范见模板「填写说明」sheet；公式用 `$...$` 包裹（LaTeX 语法）
4. 删除试题 = 软删除进回收站；彻底删除仅在回收站内操作
5. 上传文件存 `backend/uploads/`（图片 ≤5MB、音频 ≤20MB），备份 JSON 不含上传文件，迁移时请一并拷贝
6. 智能组卷分层算法：难度分带比例抽题 → 不足回补 → 缺口提示；平行卷 = 生成时携带 `excludeIds`
7. 录分保存为「整份覆盖」语义；在线交卷覆盖该生全部成绩
