# 国际课程组卷系统（06-组卷系统）

> 成都智慧象留学 · 教研组卷工作台　|　交付日期：2026-09-28（v3 在线答题增强同日）　|　独立于「学生进度追踪系统」的新系统

面向国际课程教学场景（IELTS / TOEFL / A-Level / AP）的教研系统，**以组卷为核心**：登录即达组卷台，一键组卷；题库、在线考试与成绩分析围绕组卷协作。
与学生进度追踪系统（04，端口 8686）同一套技术栈与视觉规范，本系统独立运行在 **8687 端口**，两套系统可同时开启。

## 功能总览

| 模块 | 说明 |
|---|---|
| **题库** | 7 种题型（单选/多选/判断/填空/简答/写作/口语）× 难度 1–5；**听力音频附件**（mp3/wav/m4a ≤20MB）；**题目配图**；**KaTeX 数学公式**（`$...$` 包裹，离线渲染）；**知识点大纲**（两级树，按科目维护，录题点选）；**共享/私有**（私有题仅创建者与总监可见可改）；星标收藏、批量操作、回收站、**相似度查重**（归一化 + 序列相似 ≥82% 提醒）；六维筛选；Excel 导入导出 |
| **总览**（辅助） | 题库/试卷统计、题型/难度/科目分布、近 8 周录题与组卷趋势、高频使用题目 Top 5、最近试卷直达打印 |
| **组卷台**（核心，登录默认页） | **双栏工作区**：左侧试题池筛选挑题点 + 入卷，右侧试卷实体实时成型——大题分区自动按题型建立、可改名/排序/删除，每题调分/换题（同池候选按难度就近排序点选）/区内调序，顶部实时显示题数/总分/时长/**难度构成条**与高频用题预警；工具条含 A/B 卷、状态、**蓝图载入（按当前卷反推存蓝图）**；「按配置生成」弹窗含**快速模式**（选科目+题数→按题型分布自动配卷凑 100 分）与**精确模式**（题型×数量×分值+难度三层分布），生成结果直接填入工作区，缺口与分布偏离如实提示；**保存并打印**一键出卷 |
| **试卷库** | 调序/换题/改分/添加试题、复制、定稿草稿、A/B 卷标记 |
| **考试与成绩** | 创建考试（花名册勾选 + 批量粘贴）；**开启在线作答生成 6 位答题码**（一键复制学生链接）；纸质按题录分（**客观题 ✓/✗ 按标准答案速判**、答题卡照片上传对照、学生在线作答原文对照批阅）；**成绩单 Excel 导出** |
| **学生在线答题** ⭐ | 免登录：`answer.html` 凭答题码 + 姓名进入（自动匹配考生名单）；听力音频播放器、公式渲染、图片展示；选择题点选 / 判断题对错 / 主观题文本作答；**交卷客观题自动判分**（单选/判断全对满分，多选全对满分、漏选半分、错选 0 分），主观题进教师批阅队列；交卷即显示客观题得分 |
| **统计报告** | 平均/最高/最低/中位数/及格率、分数段分布、成绩排名🥇🥈🥉、每题得分率（<50% 红色预警）、薄弱知识点榜、讲评建议 |
| **打印页** | 学生卷 / 教师卷（文末附答案解析）/ **答题卡**（涂卡气泡、判断题对错、填空作答行、简答/写作作答框）；密封线开关；公式随卷渲染，听力题印注记提示 |
| **审计与数据管理** | 全程留痕、按动作筛选；一键备份（全库 JSON）/ 从备份恢复 |

## 快速启动

```bash
cd 06-组卷系统
python backend/app.py     # 服务端模式（推荐）：Flask + SQLite 持久化 → http://localhost:8687
python server.py          # 纯静态演示模式：sessionStorage，关标签页即重置（汇报现场兜底）
```

或双击 `一键启动-组卷系统.bat`。前端 `js/api.js` 自动探测 `POST /api/ping`，两种模式页面代码通用、
核心功能对齐（在线答题/报告/回收站/蓝图/知识树演示模式同样可用，上传/导入/审计除外）。

**依赖**：Python 3.11+，`pip install -r backend/requirements.txt`（flask、openpyxl）。演示模式无任何依赖。
**KaTeX 已内置离线包**（`vendor/katex/`），公式渲染不依赖外网。

## 在线答题规则

- 答题码由创建考试时勾选「开启学生在线作答」生成（6 位，去除易混字符），也可在列表随时开启/关闭
- 学生须使用与考生名单一致的姓名；交卷后客观题立即判分并写入成绩，重复交卷整份覆盖
- 主观题（填空/简答/写作/口语）存作答原文，教师在「录分」视图对照原文打分
- 考试完结（状态改「已完结」）后学生不能再进入
